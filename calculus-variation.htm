The Calculus of Variations

Brian Keng

2017-02-26 10:08

Source

This post is going to describe a specialized type of calculus called variational calculus. Analogous to the usual methods of calculus that we learn in university, this one deals with functions of functions and how to minimize or maximize them. It's used extensively in physics problems such as finding the minimum energy path a particle takes under certain conditions. As you can also imagine, it's also used in machine learning/statistics where you want to find a density that optimizes an objective 1. The explanation I'm going to use (at least for the first part) is heavily based upon Svetitsky's Notes on Functionals, which so far is the most intuitive explanation I've read. I'll try to follow Svetitsky's notes to give some intuition on how we arrive at variational calculus from regular calculus with a bunch of examples along the way. Eventually we'll get to an application that relates back to probability. I think with the right intuition and explanation, it's actually not too difficult, enjoy!


From multivariable functions to functionals

Consider a regular scalar function 𝐹(𝑦)F(y), it maps a single value 𝑦y to a single value 𝐹(𝑦)F(y). You can differentiate it to get 𝑑𝐹𝑑𝑦=𝐹′(𝑦)dFdy=F′(y). Another way to think about it is starting at 𝑦1y1, move a tiny step away, call it 𝑑𝑦dy, then 𝐹F will change by its differential:

𝑑𝐹=𝐹(𝑦1+𝑑𝑦)−𝐹(𝑦1)=𝑑𝐹𝑑𝑦|𝑦1𝑑𝑦(1)(1)dF=F(y1+dy)−F(y1)=dFdy|y1dy

Now let's consider the same situation with a multivariable function 𝐹(𝑦1,𝑦2,…,𝑦𝑛)F(y1,y2,…,yn). It maps a set of values 𝑦1,…,𝑦𝑛y1,…,yn to a single value 𝐹(𝑦1,𝑦2,…,𝑦𝑛)F(y1,y2,…,yn). You can also differentiate it by taking partial derivatives: 𝑑𝐹𝑑𝑦1,…,𝑑𝐹𝑑𝑦𝑛dFdy1,…,dFdyn. Similarly, if I move a tiny step away in each direction 𝑑𝑦1,…,𝑑𝑦𝑛dy1,…,dyn, starting from points 𝑦11,…,𝑦1𝑛y11,…,yn1, the total differential of the function is:

𝑑𝐹=∂𝐹∂𝑦1∣∣∣𝑦11𝑑𝑦1+…+∂𝐹∂𝑦𝑛∣∣∣𝑦1𝑛𝑑𝑦𝑛(2)(2)dF=∂F∂y1|y11dy1+…+∂F∂yn|yn1dyn

So far we have only touched upon derivatives and differentials of a function 𝐹(𝑦1,𝑦2,…,𝑦𝑛)F(y1,y2,…,yn) with independent variables 𝑦1,𝑦2,…,𝑦𝑛y1,y2,…,yn. If you squint hard enough, you may already start to see where we're going with this: we can view the input to the function not just as independent variables, but collectively as a group of variables derived from a function 𝑦y (i.e. 𝑦𝑖=𝑦(𝑖),𝑖∈yi=y(i),i∈N). If we have an infinite set of these variables, then 𝐹F is no longer just a function of independent variables but a function of a function 𝑦(𝑖)y(i).

Of course this is just some intuition and not at all precise but let's keep going to see where this can take us. Our independent points can be seen as sampling some function 𝑦y on some interval [𝑎,𝑏][a,b]. Let's say we want to sample 𝑁N points, each 𝜖ϵ distance apart, i.e. 𝑁𝜖=𝑏−𝑎Nϵ=b−a. The 𝑛𝑡ℎnth point will be at 𝑥𝑛=𝑎+𝑛𝜖xn=a+nϵ, so our sample point becomes 𝑦𝑛=𝑦(𝑥𝑛)=𝑦(𝑎+𝑛𝜖)yn=y(xn)=y(a+nϵ). As 𝑁→∞,𝜖→0N→∞,ϵ→0, our sampled points 𝑦𝑛yn become an increasingly accurate representation of our original function 𝑦(𝑥)y(x).

Our original "function" 𝐹F can now be thought of as a function of a set of variables {𝑦𝑛}{yn} resulting in 𝐹({𝑦𝑛})F({yn}). As 𝑁→∞N→∞, the original function 𝐹F transforms into a function of an infinite set of variables, or in another way, a function of a function. The mapping is called a functional, which we generally write with square brackets 𝐹[𝑦]F[y]. So instead of taking a fixed number of independent variables and outputting a value, it takes an infinite number of variables, defined by 𝑦(𝑥)y(x) on the interval [𝑎,𝑏][a,b], and outputs a value!

Let's pause for a second and summarize:

  • A function 𝑦(𝑥)y(x) takes as input a number 𝑥x and returns a number.

  • A functional 𝐹[𝑦]F[y] takes as input a function 𝑦(𝑥)y(x) and returns a number.

Another way to say this is 𝐹[𝑦(𝑥)]F[y(x)] takes all the values of 𝑦(𝑥)y(x) at all the values of 𝑥x (for that 𝑦y) and maps it to a single number. Let's take a look at a few examples to make things concrete.

Example 1: A simple functional

The simplest functional just evaluates the input function at a particular value.

Define 𝐹[𝑦]=𝑦(3)F[y]=y(3).

  • 𝐹[𝑦=𝑥]=3F[y=x]=3

  • 𝐹[𝑦=𝑥2]=(3)2=9F[y=x2]=(3)2=9

  • 𝐹[𝑦=ln3(𝑥)]=ln3(3)=1F[y=ln3⁡(x)]=ln3⁡(3)=1

Example 2: An integral functional

Many useful functionals will take a definite integral of the input function as a means to map it to a number.

Define 𝐹[𝑦]=∫10𝑦(𝑥)𝑑𝑥F[y]=∫01y(x)dx.

  • 𝐹[𝑦=𝑥]=∫10𝑥𝑑𝑥=12F[y=x]=∫01xdx=12

  • 𝐹[𝑦=𝑥2]=∫10𝑥2𝑑𝑥=13F[y=x2]=∫01x2dx=13

  • 𝐹[𝑦=𝑒𝑥]=∫10𝑒𝑥𝑑𝑥=𝑒−1F[y=ex]=∫01exdx=e−1

Example 3: Functionals with derivatives

Since we're dealing with functions as inputs, the functional can also involve the derivative of an input function.

A functional that defines the arc length of a curve:

𝐿[𝑦]=∫𝑏𝑎1+(𝑑𝑦𝑑𝑥)2‾‾‾‾‾‾‾‾‾‾√𝑑𝑥L[y]=∫ab1+(dydx)2dx

Notice that we're using the derivative of 𝑦(𝑥)y(x) instead of the function itself. Solving for 𝑎=0,𝑏=1,𝑦=𝑥a=0,b=1,y=x, we get:

𝐿[𝑦=𝑥]=∫101+(𝑑(𝑥)𝑑𝑥)2‾‾‾‾‾‾‾‾‾‾‾√𝑑𝑥=2‾√∫10𝑑𝑥=2‾√L[y=x]=∫011+(d(x)dx)2dx=2∫01dx=2

A common form of functionals that in appear in many contexts is:

𝐽[𝑦]=∫𝑏𝑎𝐹(𝑥,𝑦(𝑥),𝑦′(𝑥))𝑑𝑥 for 𝑥=[𝑎,𝑏], 𝑎≤𝑏, 𝑦(𝑎)=𝑦̂ 𝑎, 𝑦(𝑏)=𝑦̂ 𝑏(3)J[y]=∫abF(x,y(x),y′(x))dx(3) for x=[a,b], a≤b, y(a)=y^a, y(b)=y^b

Which is mostly just saying that 𝑦(𝑥)y(x) is well behaved over 𝑥∈[𝑎,𝑏]x∈[a,b]. In more detail, we want these conditions to be satisfied for any 𝑦(𝑥)y(x) we plug in: 𝑦(𝑥)y(x) being a single-valued function, smooth so that 𝑦′(𝑥)y′(x) exists as well as the integral defined in Equation 3, and the boundary conditions (𝑥=[𝑎,𝑏],𝑎≤𝑏,𝑦(𝑎)=𝑦̂ 𝑎,𝑦(𝑏)=𝑦̂ 𝑏x=[a,b],a≤b,y(a)=y^a,y(b)=y^b) are satisfied.


Functional Derivatives

Now it's finally time to do something useful with functionals! As with regular calculus, whose premier application is finding minima and maxima, we also want to be able to find the extrema of functionals. It turns out we can define something analogous to a derivative unsurprisingly called a functional derivative. Let's see how we can intuitively build it up from the same multivariable function from above.

Let's take another look at the total differential in Equation 2 again, but re-write it this time as a sum:

𝑑𝐹=∑𝑖=1𝑁∂𝐹∂𝑦𝑖∣∣∣𝑦1𝑖𝑑𝑦𝑖(4)(4)dF=∑i=1N∂F∂yi|yi1dyi

Again, if you squint hard enough, as 𝑁→∞N→∞, 𝑦𝑖yi approximates our 𝑦(𝑥)y(x), and our sum turns into an integral of a continuous function (recall the domain of our function 𝑦(𝑥)y(x) was 𝑥∈[𝑎,𝑏]x∈[a,b]).

𝑑𝐹=∫𝑏𝑎𝛿𝐹𝛿𝑦(𝑥)∣∣∣𝑦1(𝑥)𝛿𝑦(𝑥)𝑑𝑥(5)(5)dF=∫abδFδy(x)|y1(x)δy(x)dx

The meaning of Equation 5 is the same as Equation 4: a small change in 𝐹F is proportional to a sum of small changes in each direction 𝛿𝑦(𝑥)δy(x) (step size) multiplied by the derivative for each direction 𝛿𝐹𝛿𝑦(𝑥)δFδy(x) (slope), where we can think of 𝑥x as a continuous index (analogous to 𝑖i). As a result, the functional derivative is defined by:

𝛿𝐹𝛿𝑦(𝑥)(6)(6)δFδy(x)

This is analogous to the derivative at each of the "independent variables" 𝑦(𝑥)y(x), which is the same concept as the gradient for multivariate functions.

Equation 5 then becomes a directional derivative, where we can interpret as the rate of change of 𝐹F as we are moving through "point" 𝑦1(𝑥)y1(x) in the direction of 𝛿𝑦(𝑥)δy(x) (check out this tutorial on directional derivatives for a good intuitive refresher on the subject).

This explanation takes us from gradients to functional derivatives but we can also define it in terms of limits. Using the analogy of directional derivatives from above, if we have the functional derivative at the multivariate "point" 𝑦(𝑥)y(x) moving in the multivariate "direction" of an arbitrary function 𝜂(𝑥)η(x) then we can formulate the limit as:

lim𝜖→0𝐹[𝑦(𝑥)+𝜖𝜂(𝑥)]−𝐹[𝑦(𝑥)]𝜖=∫𝛿𝐹𝛿𝑦(𝑥)𝜂(𝑥)𝑑𝑥(7)(7)limϵ→0F[y(x)+ϵη(x)]−F[y(x)]ϵ=∫δFδy(x)η(x)dx

which, if you think hard enough about, results in the same integral as Equation 5. This also means the functional derivative is a function (natural extension from the multivariate point analogy where the number of points is infinite within an interval). We also define 𝛿𝑦δy as 𝜖𝜂(𝑥)ϵη(x) and call it the variation of 𝑦y.

Of course, there's no guarantee that the functional derivative exists. That's where formal definitions and rigorous mathematics comes in, which is beyond the scope of this post. Also important to mention is that we can have higher order functional derivatives that can be defined in a very similar way. For now, let's just focus on simple cases where everything plays nicely.

Why the name variational calculus?

A variation of a functional is the small change in a functional's value due to a small change in the functional's input. It's the analogous concept to a differential for regular calculus.

We've already seen an example of a variation in Equation 5, which is the first variation of the functional 𝐹F:

𝛿𝐹(𝑦,𝜂)=∫𝛿𝐹𝛿𝑦(𝑥)𝜂(𝑥)𝑑𝑥(8)(8)δF(y,η)=∫δFδy(x)η(x)dx

As mentioned above the term 𝜖𝜂(𝑥)ϵη(x) is also called a variation of input 𝑦y, which is analogous to the infinitesimally small 𝜖ϵ in regular calculus.

The first variation and higher order variations define the respective functional derivatives and can be derived by taking the coefficients of the Taylor series expansion of the functional. More details can be found here Advanced Variational Methods In Mechanics Chapter 1: Variational Calculus Overview.

Example 4: Computing a simple functional derivative

Let's try to find the functional derivative of a simple functional:

𝐹[𝑦(𝑥)]=∫10𝑦(𝑥)2𝑑𝑥(9)(9)F[y(x)]=∫01y(x)2dx

We can calculate this by going back to Equation 5 and computing its first variation: 𝑑𝐹=𝐹[𝑦+𝛿𝑦]−𝐹[𝑦]dF=F[y+δy]−F[y]. Start by computing 𝐹[𝑦+𝛿𝑦]F[y+δy]:

𝐹[𝑦+𝛿𝑦]=∫10[𝑦(𝑥)+𝛿𝑦(𝑥)]2𝑑𝑥=∫10𝑦(𝑥)2+2𝑦(𝑥)𝛿𝑦(𝑥)+𝛿𝑦(𝑥)2𝑑𝑥=∫10𝑦(𝑥)2+2𝑦(𝑥)𝛿𝑦(𝑥)+𝛿𝑦(𝑥)2𝑑𝑥=𝐹[𝑦]+∫102𝑦(𝑥)𝛿𝑦(𝑥)𝑑𝑥+∫10𝛿𝑦(𝑥)2𝑑𝑥(10)F[y+δy]=∫01[y(x)+δy(x)]2dx=∫01y(x)2+2y(x)δy(x)+δy(x)2dx=∫01y(x)2+2y(x)δy(x)+δy(x)2dx(10)=F[y]+∫012y(x)δy(x)dx+∫01δy(x)2dx

From Equation 10, we know that in the limit 𝛿𝑦→0δy→0 so we can drop the last term. Finally, computing 𝑑𝐹dF we have:

𝑑𝐹=𝐹[𝑦+𝛿𝑦]−𝐹[𝑦]=𝐹[𝑦]+∫102𝑦(𝑥)𝛿𝑦(𝑥)𝑑𝑥−𝐹[𝑦]=∫102𝑦(𝑥)𝛿𝑦(𝑥)𝑑𝑥(11)dF=F[y+δy]−F[y]=F[y]+∫012y(x)δy(x)dx−F[y](11)=∫012y(x)δy(x)dx

By inspection, we can see Equation 11 resembles Equation 5, thus our functional derivative is 𝛿𝐹𝛿𝑦(𝑥)=2𝑦(𝑥)δFδy(x)=2y(x).


Euler-Lagrange Equation

Now armed with the definition of a functional derivative, we now know how to compute it from first principles. However, as with regular calculus, computing a derivative by definition can get tedious. Fortunately, there is a result that can help us compute the functional derivative called the Euler-Lagrange equation, which states (roughly):

For a given function 𝑦(𝑥)y(x) with a real argument 𝑥x, the functional:

𝐹[𝑦]=∫𝑏𝑎𝐿(𝑥,𝑦(𝑥),𝑦′(𝑥))𝑑𝑥(12)(12)F[y]=∫abL(x,y(x),y′(x))dx

has functional derivative given by:

𝛿𝐹𝛿𝑦(𝑥)=∂𝐿∂𝑦−𝑑𝑑𝑥∂𝐿∂𝑦′(13)(13)δFδy(x)=∂L∂y−ddx∂L∂y′

You can derive this equation using the method we used above (and a few extra tricks) but I'll leave it as an exercise :) For simple functionals like Equation 12, this is a very handy way to compute functional derivatives. Let's take a look at a couple more complicated examples.

Example 5: Use the Euler-Lagrange Equation to find the functional derivative of 𝐹[𝑦(𝑥)]=∫10𝑥3𝑒−𝑦(𝑥)𝑑𝑥F[y(x)]=∫01x3e−y(x)dx

Notice the second term in Equation 13 involves only 𝑦′y′, which we doesn't appear in our functional so that means it's 0. Thus, the functional derivative in this case just treats 𝑦y as a variable and the usual rules of differentiation apply:

𝛿𝐹𝛿𝑦(𝑥)=∂𝐿∂𝑦=∂(𝑥3𝑒−𝑦(𝑥))∂𝑦=−𝑥3𝑒−𝑦(𝑥)(14)(14)δFδy(x)=∂L∂y=∂(x3e−y(x))∂y=−x3e−y(x)

Example 6: Use the Euler-Lagrange Equation to find the functional derivative of 𝐹[𝑦(𝑥)]=∫10𝑥2𝑦3𝑦′4𝑑𝑥F[y(x)]=∫01x2y3y′4dx

Here we have to use all terms from Equation 13 and treat 𝑦y and 𝑦′y′ as "independent" variables:

𝛿𝐹𝛿𝑦(𝑥)=∂𝐿∂𝑦−𝑑𝑑𝑥∂𝐿∂𝑦′=3𝑥2𝑦2𝑦′4−4𝑑(𝑥2𝑦3𝑦′3)𝑑𝑥=3𝑥2𝑦2𝑦′4−8𝑥𝑦3𝑦′3(15)δFδy(x)=∂L∂y−ddx∂L∂y′=3x2y2y′4−4d(x2y3y′3)dx(15)=3x2y2y′4−8xy3y′3


Extrema of Functionals

As an exercise this is interesting enough, but the real application is when we want to minimize or maximize a functional. In a similar way to how we find a point that is an extremum of a function, we can also find a function that is an extremum a functional.

It turns out that it's pretty much what you would expect: if we set the functional derivative to zero, we'll find a stationary point of the functional where we possibly have a local minimum or maximum (i.e. a necessary condition for extrema, sometimes we might find a saddle point though). In other words, this is a place where the "slope" is zero. Let's take a look at a classic example.

Example 7: Find the shortest possible curve between the points (𝑎,𝑐)(a,c) and (𝑏,𝑑)(b,d) for which the path length along the curve is defined by ℓ(𝑓)=∫𝑏𝑎1+𝑓′(𝑥)2‾‾‾‾‾‾‾‾‾‾√𝑑𝑥ℓ(f)=∫ab1+f′(x)2dx

First define our integrand functional:

𝐿(𝑥,𝑦,𝑦′)=1+𝑓′(𝑥)2‾‾‾‾‾‾‾‾‾‾√(16)(16)L(x,y,y′)=1+f′(x)2

where (𝑥,𝑦,𝑦′)=(𝑥,𝑓(𝑥),𝑓′(𝑥))(x,y,y′)=(x,f(x),f′(x)). Pre-computing the partial derivatives of 𝐿L:

∂𝐿∂𝑦∂𝐿∂𝑦′=0=𝑓′(𝑥)1+𝑓′(𝑥)2‾‾‾‾‾‾‾‾‾‾√(17)∂L∂y=0(17)∂L∂y′=f′(x)1+f′(x)2

Plugging them into Equation 13, we can simplify the resulting differential equation:

𝑑𝑑𝑥𝑓′(𝑥)1+𝑓′(𝑥)2‾‾‾‾‾‾‾‾‾‾√𝑓′(𝑥)1+𝑓′(𝑥)2‾‾‾‾‾‾‾‾‾‾√𝑓′(𝑥)𝑓′(𝑥)2𝑓′(𝑥)𝑓(𝑥)=0=𝐶=𝐶1+𝑓′(𝑥)2‾‾‾‾‾‾‾‾‾‾√=𝐶21−𝐶2=𝐶1−𝐶2‾‾‾‾‾‾‾√:=𝐴=𝐴𝑥+𝐵(18)ddxf′(x)1+f′(x)2=0f′(x)1+f′(x)2=Cf′(x)=C1+f′(x)2f′(x)2=C21−C2f′(x)=C1−C2:=A(18)f(x)=Ax+B

where we introduce a constant 𝐶C after integrating, define a new constant 𝐴A to be the result of a constant expression with 𝐶C, and introduce a new constant 𝐵B from the second integration. As you would expect the shortest distance between two points is a straight line (but now you can prove it!).

We can find the actual values of constants 𝐴A and 𝐵B by using our initial conditions (𝑎,𝑐)(a,c) and (𝑏,𝑑)(b,d) since we know the function has to pass through our points (i.e. compute the slope and intercept of the line):

𝐴=𝑑−𝑐𝑏−𝑎𝐵=𝑎𝑑−𝑏𝑐𝑎−𝑏(19)A=d−cb−a(19)B=ad−bca−b

Now that we have a method to solve the general problem of finding extrema for a functional, we can add constraints in the mix. As you may have guessed, we can use the concept of Lagrange multipliers here (see my previous post on Lagrange Multipliers).

Given a functional in the form of Equation 12, we can add different types of constraints. The simplest type of constraint we can have is a functional constraint of the form:

𝐺[𝑦]=∫𝑏𝑎𝑀(𝑥,𝑦,𝑦′)𝑑𝑥=𝐶(20)(20)G[y]=∫abM(x,y,y′)dx=C

In this case, the solution resembles the usual method for Lagrange multipliers. We can solve this problem by building a new functional in the same vein of a Lagrangian:

𝐻[𝑦]=∫𝑏𝑎(𝐿(𝑥,𝑦,𝑦′)−𝜆𝑀(𝑥,𝑦,𝑦′))𝑑𝑥(21)(21)H[y]=∫ab(L(x,y,y′)−λM(x,y,y′))dx

Using the Euler-Lagrange equation, we can solve Equation 21 for a function 𝑦y and constant 𝜆λ, keeping in mind we are given boundary conditions at 𝑎a and 𝑏b as well as Equation 20 to help us solve for all the constants. This method also naturally extends to multiple constraints as you would expect.

The other type of constraint is just a constraint on the actual function (similar to regular Lagrange multipliers):

𝑔(𝑥,𝑦)=0(22)(22)g(x,y)=0

Here, a Lagrange multiplier function needs to be introduced and the Lagrangian becomes:

𝐻[𝑦]=∫𝑏𝑎(𝐿(𝑥,𝑦,𝑦′)−𝜆(𝑥)𝑔(𝑥,𝑦))𝑑𝑥(23)(23)H[y]=∫ab(L(x,y,y′)−λ(x)g(x,y))dx

Again, we can use the Euler-Lagrange equation to solve Equation 23, except we'll get a system of differential equations to solve (you need to take the functional derivative with respect to both 𝑦(𝑥)y(x) and 𝜆(𝑥)λ(x)).

And at long last, we can finally get to solving some interesting problems in probability! Let's take a look at a couple of examples of finding maximum entropy distributions under different constraints (check out my previous post on Maximum Entropy Distributions).

Example 8: Find the continuous maximum entropy distribution with support [𝑎,𝑏][a,b].

This is actually the same example as that appeared in my post on Maximum Entropy Distributions, but let's take another look.

First since we're finding the maximum entropy distribution, we define the differential entropy functional (we use 𝐻H here to denote entropy):

𝐻[𝑓]:=−∫𝑏𝑎𝑓(𝑥)log(𝑓(𝑥))𝑑𝑥(24)(24)H[f]:=−∫abf(x)log⁡(f(x))dx

Next, we define a functional constraint that our density must sum to 1:

𝐺[𝑓]:=∫𝑏𝑎𝑓(𝑥)𝑑𝑥=1(25)(25)G[f]:=∫abf(x)dx=1

Now put together the Lagrangian equivalent:

𝐹[𝑓]=∫𝑏𝑎𝐿(𝑥,𝑓(𝑥))𝑑𝑥=∫𝑏𝑎−𝑓(𝑥)log(𝑓(𝑥))−𝜆𝑓(𝑥)𝑑𝑥(26)F[f]=∫abL(x,f(x))dx(26)=∫ab−f(x)log⁡(f(x))−λf(x)dx

Using the Euler-Lagrange equation to find the maximum and noticing we have no derivatives of 𝑓(𝑥)f(x), we get:

𝛿𝐿𝛿𝑓(𝑥)=−log(𝑓(𝑥))−1−𝜆−log(𝑓(𝑥))=1+𝜆𝑓(𝑥)=𝑒−𝜆−1=0(27)δLδf(x)=−log⁡(f(x))−1−λ=0−log⁡(f(x))=1+λ(27)f(x)=e−λ−1

Plugging this into our constraint in Equation 25:

𝐺[𝑓]=∫𝑏𝑎𝑒−𝜆−1𝑑𝑥𝑒−𝜆−1∫𝑏𝑎𝑑𝑥𝑒−𝜆−1=1=1=1𝑏−𝑎(28)G[f]=∫abe−λ−1dx=1e−λ−1∫abdx=1(28)e−λ−1=1b−a

Now substituting back into Equation 27, we get:

𝑓(𝑥)=1𝑏−𝑎(29)(29)f(x)=1b−a

This is nothing more than a uniform distribution on the interval [𝑎,𝑏][a,b]. This means that given no other knowledge of a distribution (except its support), the principle of maximum entropy says we should assume it's a uniform distribution.

Example 9: Find the continuous maximum entropy distribution with support [−∞,∞][−∞,∞], 𝐸[𝑥]=𝜇E[x]=μ and 𝐸[(𝑥−𝜇)2]=𝜎2E[(x−μ)2]=σ2.

You may already be able to guess what kind of distribution we should end up with when we have the mean and variance specified, let's see if you're right.

We'll just transform the variance constraint into the second moment to make this a bit more symmetric:

∫∞−∞𝑓(𝑥)(𝑥−𝜇)2𝑑𝑥∫∞−∞𝑓(𝑥)𝑥2𝑑𝑥−𝜇2∫∞−∞𝑓(𝑥)𝑥2𝑑𝑥=𝜎2=𝜎2=𝜎2+𝜇2(30)∫−∞∞f(x)(x−μ)2dx=σ2∫−∞∞f(x)x2dx−μ2=σ2(30)∫−∞∞f(x)x2dx=σ2+μ2

Given this objective functional and associated constraints:

𝐻[𝑓]𝐺0[𝑓]𝐺1[𝑓]𝐺2[𝑓]:=−∫∞−∞𝑓(𝑥)log(𝑓(𝑥))𝑑𝑥:=∫∞−∞𝑓(𝑥)𝑑𝑥=1:=∫∞−∞𝑓(𝑥)𝑥𝑑𝑥=𝜇:=∫∞−∞𝑓(𝑥)𝑥2𝑑𝑥=𝜎2+𝜇2(31)H[f]:=−∫−∞∞f(x)log⁡(f(x))dxG0[f]:=∫−∞∞f(x)dx=1G1[f]:=∫−∞∞f(x)xdx=μ(31)G2[f]:=∫−∞∞f(x)x2dx=σ2+μ2

we can put together the Lagrangian functional:

𝐹[𝑓]:=∫∞−∞𝐿(𝑥,𝑓(𝑥))𝑑𝑥=∫∞−∞−𝑓(𝑥)log(𝑓(𝑥))−𝜆0𝑓(𝑥)−𝜆1𝑓(𝑥)𝑥−𝜆2𝑓(𝑥)𝑥2𝑑𝑥(32)F[f]:=∫−∞∞L(x,f(x))dx(32)=∫−∞∞−f(x)log⁡(f(x))−λ0f(x)−λ1f(x)x−λ2f(x)x2dx

Using the Euler-Lagrange equation again and setting it to 0:

−log(𝑓(𝑥))−1−𝜆0−𝜆1𝑥−𝜆2𝑥2𝑓(𝑥)=0=𝑒−(1+𝜆0+𝜆1𝑥+𝜆2𝑥2)(33)−log⁡(f(x))−1−λ0−λ1x−λ2x2=0(33)f(x)=e−(1+λ0+λ1x+λ2x2)

Now this is not going to work out so nicely in terms of plugging it back into our constraints from Equation 30 because integrals involving 𝑒𝑥2ex2 usually don't have nice anti-derivatives. But one thing to notice is that this is basically the form of a Gaussian function (you'll have to do some legwork to complete the square though):

𝑓(𝑥)=𝑒−(1+𝜆0+𝜆1𝑥+𝜆2𝑥2)=𝑎𝑒−(𝑥−𝑏)22𝑐2(34)f(x)=e−(1+λ0+λ1x+λ2x2)(34)=ae−(x−b)22c2

Further, we know from the constraints in Equation 31 that the function is normalized to 11, making this a normal distribution. Thus we can determine the values of the missing coefficients by just matching them against the definition of a normal distribution:

𝑎𝑏𝑐=12𝜋𝜎2‾‾‾‾‾√=𝜇=𝜎2(35)a=12πσ2b=μ(35)c=σ2

So by the principle of maximum entropy, if we only know the mean and variance of a distribution with support along the real line, we should assume the distribution is normal.


Conclusion

For those of us who aren't math or physics majors (* cough * computer engineers), variational calculus is an important topic that we missed out on. Not only does it have a myriad of applications in physical domains (it's the most common type of problem when searching for "variational calculus"), it also has many applications in statistics and machine learning (you can expect a future post using this topic!). As with most things, once you know enough about the individual parts (multivariable calculus, Lagrange multipliers etc.) the actual topic (variational calculus) isn't too much of a stretch (at least when you're not trying to prove things formally!). I hope this post helps all the non-mathematicians and non-physicists out there.
